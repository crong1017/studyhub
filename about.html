AI 友善的學習網站

使用 AGENTS.md 告訴 AI 如何延伸每一個新主題。

ABOUT THIS PROJECT

不是只有做出一個網站，
而是建立可延續的規則。

StudyHub 將 Goodnotes PDF 重新整理為可搜尋的學習文章，以統一的資料結構、共用模板、清楚的內容規範，讓 AI 能在既有基礎上繼續新增主題。

01

輸入筆記

從 Goodnotes 或 Google Drive 取得可公開整理的 PDF。

02

整理與核實

AI 摘要原理、公式與例子；辨識錯誤部分人工複查。

03

遵守規範

依照 AGENTS.md 填寫固定欄位與章節格式。

04

自動呈現

網站透過 JSON 資料建立分類、搜尋、卡片與內頁。

為什麼使用資料驅動架構？

所有文章都存在 data/notes.json，前端以共用版型呈現，不需要每新增一篇就重新複製 HTML。分類計數、搜尋及文章頁面都會依據資料更新。

Goodnotes PDF → AI 摘要與核實 → notes.json → 共用頁面 → GitHub Pages

內容來源與公開原則

本示範使用資料夾中計算機概論、資料結構、圖形演算法與個人研究筆記作為選題來源。公開網站內容為重新撰寫的教學摘要，沒有上傳原始 Goodnotes 或 PDF。手寫辨識不清與原專題尚待核實的地方，應保留明確說明。
